# AI 审批建议功能需求文档

> **版本**: 1.0  
> **创建日期**: 2026-03-21

## 一、功能概述

AI 审批建议功能旨在为审批人提供智能化的审批辅助，通过 AI 分析申请内容、历史记录、相似案例等信息，自动生成审批建议，帮助审批人快速做出决策。

---

## 二、用户故事

> **作为** 一位审批人，
> **我想要** 在审批时获得 AI 的智能建议，
> **以便于** 快速理解申请内容、识别潜在风险，并高效完成审批决策。

## 三、功能详情

### 3.1 触发方式

| 项目 | 描述 |
|------|------|
| **触发条件** | 审批人主动点击"获取 AI 建议"按钮 |
| **显示位置** | 审批页面（待办任务详情页） |

### 3.2 建议内容

AI 生成的建议应包含以下四部分内容：

#### 3.2.1 通过/拒绝判断
- **输出形式**：明确的"建议通过"或"建议拒绝"
- **格式示例**：
  - ✅ "建议通过：该申请符合常规差旅标准，金额在合理范围内。"
  - ❌ "建议拒绝：该报销金额超出部门月度预算上限。"

#### 3.2.2 风险预警
AI 应检测并预警以下风险类型：
- **金额异常**：金额超过正常范围
- **频率异常**：申请过于频繁
- **时间异常**：非工作时间提交、紧急申请等
- **内容可疑**：描述模糊、存在矛盾等

**格式示例**：
```
⚠️ 风险预警：
• 金额异常：本次报销金额 ¥5,000 高于该员工月均报销额 ¥1,200
• 频率异常：该员工本月已有 4 笔同类申请
```

#### 3.2.3 异常检测
AI 应识别申请中的异常点：
- 数据不一致
- 缺失必要信息
- 超出常规范围

**格式示例**：
```
🔍 异常检测：
• 发票日期与出差日期不匹配
• 缺少住宿发票
```

#### 3.2.4 补充信息
AI 应提供以下补充信息：
- **申请人历史统计**：本月申请次数、平均金额等
- **同类申请平均处理时间**
- **相关政策条款引用**

**格式示例**：
```
📊 补充信息：
• 该员工本月累计申请 5 笔，总金额 ¥8,500
• 同类申请平均处理时间：2 个工作日
• 根据《差旅费管理办法》第 3 条，单次住宿费用上限为 ¥800/天
```

### 3.3 参考依据

AI 生成建议时应参考以下信息：

| 依据类型 | 说明 |
|----------|------|
| **申请内容** | 表单填写的数据、附件、说明等 |
| **历史记录** | 该申请人过去的申请情况 |
| **公司制度** | 目前基于通用常识和最佳实践判断 |
| **相似案例** | 同一类型/类别的历史申请及审批结果 |

### 3.5 自动填入表单

点击"填入表单"按钮后，AI 建议应自动填入：

| 目标 | 内容 |
|------|------|
| **审批意见框** | 通过/拒绝判断 + 理由 |
| **申请表单** | 如 AI 建议补充信息，可填入相关字段 |

**填入后的表单示例**：
```
审批意见：
✅ 建议通过：该申请符合常规差旅标准，金额在合理范围内。
（此处文字可编辑）
```

### 3.6 可编辑性

- 审批人可以**自由修改**AI 生成的任何文字内容
- 修改后无需特殊标记

### 3.7 多轮对话

审批人点击"追问 AI"按钮后，可以进一步询问：

**示例对话**：
```
审批人：为什么你觉得这个有风险？
AI：因为该金额超过该部门月度平均报销额的 2 倍，且该员工本月已有 3 笔类似申请。

审批人：这个金额是否符合公司规定？
AI：根据差旅费管理常识，单次差旅费通常不应超过月薪的 20%。建议您核实该员工薪资水平。
```

### 3.8 历史记录

系统应记录以下信息：

| 记录项 | 说明 |
|--------|------|
| AI 建议内容 | 完整保存 AI 生成的建议 |
| 是否采纳 | 记录审批人是否使用了 AI 建议 |
| 最终审批结果 | 记录实际审批结果（用于分析 AI 准确性） |
| 时间戳 | 生成和采纳时间 |

### 选题
“基于 Flowable 工作流引擎的智能协同审批系统开发”。
### 课题简介
随着企业数字化转型的深入，传统的固定逻辑审批系统已无法满足现代组织灵活多变的业务需求。尤其是在面对复杂的会签、或签、流程回退及动态跳转等场景时，维护成本极高、扩展性差。本课题旨在设计并开发一个基于 SpringBoot 框架和 Flowable 工作流引擎的智能协同审批系统，结合了前沿的 AI 应用场景，实现审批建议的自动生成与表单指令的自然语言解析，从而提升办公协同的智能化水平。
设计要求：
采用 Java 语言，基于 SpringBoot、MySQL 及 Flowable 引擎开发，前端使用 Vue/Element。核心功能： 实现权限管理、可视化流程设计；支持申请、审批、会签、委派、回退等核心流转逻辑。动态表单： 实现自定义表单配置，支持表单数据与流程变量的动态绑定。确保系统事务一致性。
### 任务书
1．本毕业设计课题应达到的目的：
（1）培养综合运用软件工程专业知识解决企业数字化转型中复杂审批问题的能力;（2）熟练掌握 Java 语言及 SpringBoot 框架，深入理解并应用 Flowable 工作流引擎的核心机制;
（3）熟练使用 Vue/Element 进行前端开发，以及 MySQL 数据库的设计与优化；
（4）探索大语言模型（LLM）在办公自动化中的应用，实现智能化审批辅助功能；
（5）通过完整项目的开发，强化代码书写规范及软件工程文档的撰写能力。
2．本毕业设计课题任务的内容和要求
主要内容：
（1）基于 Flowable 引擎实现符合 BPMN 2.0 标准的流程驱动 ；
（2）开发支持申请、审批、会签、或签、委派、回退及动态跳转等复杂的流转逻辑 ；
（3）实现可视化的流程设计器，并开发自定义表单配置功能，支持表单数据与流程变量的动态绑定；
（4）集成大模型接口，实现审批建议的自动生成以及表单指令解析与流程发起功能；
（5）构建基于 RBAC 模型的多用户权限管理系统，确保系统事务一致性与安全性。
技术要求：
（1）使用Java 语言、SpringBoot 框架、Flowable 工作流引擎开发；
（2）使用Vue.js 框架、Element UI 组件库等方式实现前端程序架构；
（3）使用IntelliJ IDEA为开发工具，用来进行代码的编写和调试；
（4）集成主流大语言模型（如 GPT 或国产大模型）API。
工作要求：
（1）查阅与本毕业设计课题相关的参考文献10篇以上；
（2）编写毕业设计开题报告，其中包括2千字左右的文献综述；
（3）完成与本专业相关的外文技术资料翻译，译文不少于3千汉字；
（4）根据毕业设计课题要求进行相关软件开发；
（5）编写1.5万字左右的毕业设计说明书。

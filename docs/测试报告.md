## 测试发现及修复的问题

### 问题 1: 数据完整性违例（初始化管理员用户失败）

**现象**: 调用 `/api/auth/bootstrap` 接口返回 `"error": "Data integrity violation"`

**根本原因**: `sys_user` 表的 `login_failures` 列定义为 `NOT NULL` 但没有默认值，而 `RbacService.createUser()` 方法未设置该字段。

**修复方案**: 在 `RbacService.createUser()` 中添加 `user.setLoginFailures(0)`。

**代码位置**: `src/main/java/com/flowablecollab/approval_system/service/RbacService.java`

```java
public SysUser createUser(String username, String password, Long deptId, Integer status) {
    // ... existing code ...
    user.setTwoFactorEnabled(0);
    user.setLoginFailures(0);  // ← 新增
    return sysUserRepository.save(user);
}
```

---

### 问题 2: 工作流请求被拒绝（Forbidden 错误）

**现象**: 调用 `/api/workflow/requests` 接口返回 `"error": "Forbidden"`

**根本原因**: `SecurityConfig` 中配置了 `/api/workflow/requests` 需要 `EMPLOYEE` 角色，但系统中未创建该角色。

**修复方案**: 创建 `EMPLOYEE` 角色并分配给所有用户。

**安全配置**: `src/main/java/com/flowablecollab/approval_system/config/SecurityConfig.java`

```java
.requestMatchers(HttpMethod.POST, "/api/workflow/requests").hasRole("EMPLOYEE")
```

**操作步骤**:
```bash
# 创建 EMPLOYEE 角色
curl -X POST http://localhost:8080/api/rbac/roles \
  -H "Content-Type: application/json" \
  -d '{"roleCode": "EMPLOYEE", "roleName": "Employee"}'

# 分配角色给用户
curl -X POST http://localhost:8080/api/rbac/assign \
  -H "Content-Type: application/json" \
  -d '{"userId": 4, "roleId": 3}'
```

---

### 问题 3: 任务完成时数据完整性违例

**现象**: 调用 `/api/workflow/tasks/{id}/complete` 返回 `"error": "Data integrity violation"`

**根本原因**: `biz_request_log` 表的 `operator_id` 列不允许为空。当使用用户名（如 "manager"）而非用户 ID 时，`parseLongSafe()` 方法返回 `null`。

**修复方案**: 修改 `parseLongSafe()` 方法，使其能够解析用户名为用户 ID。

**代码位置**: `src/main/java/com/flowablecollab/approval_system/service/WorkflowService.java`

```java
private Long parseLongSafe(String value) {
    if (value == null || value.isBlank()) {
        return null;
    }
    try {
        return Long.parseLong(value);
    } catch (NumberFormatException ex) {
        // ← 新增：尝试解析为用户名
        return sysUserRepository.findByUsername(value).map(SysUser::getId).orElse(null);
    }
}
```

```java
private Long resolveApplicantId(Long requestedApplicantId) {
    Long currentUserId = SecurityUtils.currentUserId();
    if (currentUserId == null) {
        throw new ForbiddenOperationException("Unauthorized");
    }
    if (requestedApplicantId == null) {
        return currentUserId;
    }
    boolean idMatch = requestedApplicantId.equals(currentUserId);
    boolean hasAdminRole = SecurityUtils.hasAnyRole("ADMIN", "SYS_ADMIN");
    if (idMatch || hasAdminRole) {
        return requestedApplicantId;
    }
    // ← 临时添加的详细错误信息
    throw new ForbiddenOperationException("applicantId must match current login user (requested: " + requestedApplicantId + ", current: " + currentUserId + ", idMatch: " + idMatch + ", hasAdminRole: " + hasAdminRole + ")");
}
```

# 需求分析文档

> 本文档基于实际代码实现反向推导，描述系统已实现的功能需求。原始需求草稿 `requirements-refined.md` 已废弃。

## 1. 系统概述

本系统是一个基于 Flowable 工作流引擎的智能协同审批系统，支持多类型审批流程（单人审批、会签、或签、顺序审批），集成 AI 大语言模型提供审批建议和智能表单解析，具备完整的 RBAC 权限体系。

## 4. 审批状态机

```
Draft → Submitted → InApproval → Approved/Rejected/Returned
                  ↓
              Cancelled
```

### 4.1 申请单状态

| 状态码 | 状态 | 说明 |
|--------|------|------|
| 0 | Draft | 草稿 |
| 1 | Submitted | 已提交 |
| 2 | InApproval | 审批中 |
| 3 | Approved | 已通过 |
| 4 | Rejected | 已拒绝 |
| 5 | Returned | 已退回 |
| 6 | Cancelled | 已撤销 |
| 7 | Suspended | 已挂起 |

### 4.2 任务状态

| 状态码 | 状态 | 说明 |
|--------|------|------|
| 0 | Ready | 待认领 |
| 1 | Claimed | 已认领 |
| 2 | Delegated | 委派中 |
| 3 | Completed | 已完成 |
| 4 | Returned | 已回退 |

## 5. 审批操作类型

| 操作 | 说明 |
|------|------|
| SUBMIT | 提交申请 |
| CLAIM | 认领任务 |
| APPROVE | 审批通过 |
| REJECT | 审批拒绝 |
| DELEGATE | 委派任务 |
| RESOLVE | 被委派人处理 |
| REASSIGN | 转办任务 |
| RETURN | 回退 |
| AUTO_COMPLETE | 自动完成 |
| CANCEL | 撤销 |
| SUSPEND | 挂起 |
| ACTIVATE | 激活 |
| SAVE_DRAFT | 保存草稿 |

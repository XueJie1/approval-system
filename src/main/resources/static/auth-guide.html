🔐 认证鉴权体系使用指南

📋 功能特性

  • JWT 无状态认证
  • 双因素认证 (2FA/TOTP)
  • 恢复码机制
  • 账户锁定保护
  • 登录日志审计
  • IP 地址和 User-Agent 记录
  • 基于角色的访问控制 (RBAC)

🚀 快速开始

1. 初始化管理员账户

POST /api/auth/bootstrap
{ "username": "admin", "password": "admin123" }

2. 用户登录

POST /api/auth/login
{ "username": "user@example.com", "password": "password123" }
注意： 如果启用了 2FA，返回中将包含 twoFactorRequired: true 和 challengeToken

3. 2FA 验证（如启用）

POST /api/auth/login/2fa
{ "challengeToken": "eyJ0eXAiOiJKV1QiLCJhbGc...", "code": "123456" }

🔑 2FA 管理 API

1. 获取 2FA 设置

GET /api/auth/2fa/setup 需要认证

2. 启用 2FA

POST /api/auth/2fa/enable 需要认证
{ "code": "123456" }

3. 禁用 2FA

POST /api/auth/2fa/disable 需要认证
{ "code": "123456" }

4. 生成恢复码

POST /api/auth/2fa/recovery/generate 需要认证
重要： 恢复码只会在生成时显示一次，请妥善保管！

5. 使用恢复码登录

POST /api/auth/2fa/recovery/validate 需要认证
{ "code": "1234-5678" }

📊 登录日志管理（管理员）

1. 查询登录日志

GET /api/admin/login-logs 需要 ADMIN 角色
参数： - page: 页码（默认 0） - size: 每页数量（默认 20） - userId: 用户 ID（可选） - username: 用户名（可选） - loginStatus: 登录状态 0=成功 1=失败（可选） - startDate: 开始日期（可选） - endDate: 结束日期（可选）

2. 查询单个日志

GET /api/admin/login-logs/{id} 需要 ADMIN 角色

🛡️ 安全特性说明

账户锁定机制

连续 5 次登录失败后，账户将被锁定 30 分钟。

JWT Token

  • 访问令牌：有效期 120 分钟
  • 2FA 挑战令牌：有效期 5 分钟
  • 使用 HMAC-SHA256 签名

密码安全

  • 使用 BCrypt 加密存储
  • 不支持明文密码
